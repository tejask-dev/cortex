# Code of conduct

Treat contributors and users with respect. Discuss ideas and evidence directly while recognizing that people have different backgrounds and experience. Give constructive feedback, credit others' work and correct mistakes without personal attacks.

Harassment, threats, discriminatory abuse, unwanted sexual attention, deliberate disruption and publication of another person's private information are not acceptable. Do not share private vault contents, credentials or personal correspondence in issues or examples.

Maintainers may edit or remove inappropriate contributions, restrict participation or block accounts to protect the community. Apply these measures proportionately and explain the relevant behavior when doing so is safe.

Report concerns privately to a repository maintainer through an available private channel. If no private channel is listed, ask a maintainer to establish one without including sensitive details in a public issue. No fixed response time is promised.

This code applies in project issues, discussions, pull requests and other spaces maintained for Cortex, and when representing the project in public.
